# 第一遍：从 CRL 实测数据到结果

Windows 用户先按 [直接运行指南](12_windows_quickstart.md)下载完整包。开发者按 README 安装源码环境。WSVT / WXST 默认使用 BB11 金刚石 CRL 实测数据，具体来源和结果示意见 [CRL 案例](14_crl_example.md)。

1. 打开散斑界面，选择 C++ CPU 和 WXST，点击“载入 CRL 实测示例”，再运行。
2. 换成 WSVT，再次载入示例。它使用完整100对扫描帧，WXST 使用其中第001对。
3. 查看位移 px、偏折角 rad 和相位 rad，保存本次配置、数值结果和来源记录。
4. 点击“Zernike 分解 →”，对真实 CRL 重建相位选择圆瞳并分析。
5. 用自己的数据复跑时，重新浏览选择输入，填写自己的实验标定，输出到新目录。

## 命令行复跑

在源码环境执行 `python -m wfs_starter demo --case wxst --output outputs/crl_first`。源码版首次需要下载 CRL 数据；Windows 完整包内已含数据。可用相同命令将 case 改为 wsvt，或者用 all 运行五案例。散斑优先使用可用的 C++ CPU，否则用 Python 参考。

`config.json`记录实际输入路径和参数，`results/results.npz`保存数组，`metadata.json`保存标定与约定。输入来自随包数据或自己的运行缓存，不在每个结果目录重新复制100对帧。搬移电脑后重新载入CRL示例生成本机路径，不能直接复用别人配置里的绝对路径。

## 实测数据与解析控制的区别

| 案例 | 输入 | 检查什么 |
|---|---|---|
| WXST | BB11 CRL 第001对，512² uint16 原值裁剪 | 数据配对、方向、有限输出、透镜曲面趋势 |
| WSVT | BB11 CRL 全部100对，同一ROI | 扫描变化、逐帧配对、跨后端一致性、输出来源 |
| 光栅 | 明确解析梯度的两方向载频 | 已知相位的解调与积分 |
| Hartmann | 已知偏移的孤立Gaussian光斑 | 质心和偏折换算 |
| Zernike | 已知15项解析系数 | 圆瞳、单位、系数恢复；真实CRL分析从散斑结果接入 |

CRL 不是人造刚体平移图，不能给它编造“已知位移”和 EPE 真值。report.json 中散斑 passed 表示成功执行与输出；解析控制另使用已知答案的数值检查。旧随机纹理控制的结果、失败和数值现象保留在历史版本及 validation 中，当前示例不再复用随机图。

## 常见失败

| 提示 | 处理 |
|---|---|
| 找不到程序 / 依赖 | Windows下载完整包；源码用户按README准备独立环境 |
| 找不到CRL数据 | 完整包必须全部解压；源码版首次联网下载，或解压发布的数据ZIP到example-data/crl-bb11-v1 |
| 文件校验失败 | 重新取得发布数据包；不会用随机图替代损坏帧 |
| WSVT temporal variation | 需要真实跨帧纹理变化，不能复制一帧凑数 |
| 参数 / 标定缺失 | 填写与该实验相符的像元、距离、能量与扫描配对 |
| 输出目录已存在 | 使用新的目录保留旧结果 |

Python API 在 Windows 多进程使用时，应放入 `if __name__ == '__main__':` 中调用。推荐先用界面或命令行入口。
