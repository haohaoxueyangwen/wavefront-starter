# 接入真实数据：先补齐实验记录

先把师妹使用的少量数据和实验记录放在独立目录，从 [配置模板入口](../examples/README.md) 复制对应模板填写。模板中的 `null` 表示待填写的标定或圆瞳项。当前散斑示例来自 BB11 CRL：12.4 keV、1.625 μm、历史距离 0.4845 m，具体来源见 [CRL 案例](14_crl_example.md)。这些值不能直接套用到其他实验。光栅、Hartmann 和解析 Zernike 控制另使用各自明确标注的演示参数。

## 输入与坐标

- CLI 支持有限数值的二维灰度 NPY、TIFF 等 Pillow 可读图；不支持彩色图和多页 TIFF 自动展开。多页文件应先明确拆出帧。
- 数组为 `image[row,column] = image[y,x]`。`ux_px` 正值向图像右，`uy_px` 正值向图像下。
- 散斑的参考 / 样品必须同形状、使用同一 ROI；Python 参考实现要求正方形，原生 CPU / GPU 可接受符合窗口限制的矩形。WSVT 为 `[frame,row,column]`，配置显式列出 pairs。网页可以按自然文件名排序生成配对表，生成后仍需人工核对扫描位置。
- dark/flat 与每一帧尺寸一致，计算 `(I-dark)/(flat-dark)`，无平场时仅减背景。负值裁为 0；坏点必须事先处理并记录，不能在未知情况下将黑色区域当有效测量。
- 所有配置键注明单位：能量 eV、像元和距离 m、位移 px、相位 rad。Zernike 输入可为 rad 或 m，输出系数保持输入单位。
- 教学 Zernike 的 CLI 输入要求有限数组；直接 `zernike_fit` API 可按有限值掩膜拟合。完整 Zernike 接收二维相位 NPY，可保留瞳外 NaN，但所选圆瞳内必须全为有限值，且采样足以拟合所选项数。

## 每组数据必须记录

| 内容 | 最少记录 |
|---|---|
| 身份 | 日期、束线/装置、样品、操作者、原始文件名、共享范围 |
| 采集 | reference/sample 定义、帧序、曝光、能量、是否饱和 |
| 坐标 | ROI 在原图的位置、裁剪前尺寸、转置/翻转/旋转、探测器方向 |
| 几何 | 有效像元尺寸、放大率、距离起止面及误差来源 |
| 校正 | 背景、平场、坏点掩膜、剔除帧及原因 |
| 标定 | 对照光学状态、偏折正负号、光栅灵敏度或 Hartmann 网格/参考点 |
| 验收 | 已知控制、误差计算区域、重复性、失败标准 |

## 各路线特有项目

WXST：一对图像中的空间纹理要有足够对比度，搜索窗口必须覆盖预期位移。位移到角度采用参考实现的去均值处理；绝对倾斜需要另外处理。

WSVT：每一对 reference/sample 应对应同一散斑调制位置或明确的配对条件，整栈空间坐标一致；跨帧无变化或未配准会破坏时间向量。当前 CRL 例子使用真实100对扫描帧；GPU 固定100对，CPU / Python 可接其他有效帧数，但帧数需按采集条件与数据质量选择。

光栅：中心为 fftshift 后的 `[row,column]`，窗口为两个正奇数。先人工確認 x/y 边带及方向。未标定时只输出差分条纹相位。要输出波前，必须填写两个有符号的 `phase_gradient_scale_rad_per_m_per_fringe_rad`、两个空间采样间距和 `calibration_source`；这两项采样间距应对应所重建波前平面的坐标。系数需由真实光栅周期、几何放大、传播距离、波长及边带符号推导或标定，不能套用例子的 1e6。

Hartmann：本版只处理等间距固定网格、每格一个孤立光斑。非规则孔阵列、错配、跨格移动、重叠光斑和多脉冲混合，应转回完整研究工程。`distance_m` 的定义必须符合实际光线偏折模型；示例中仅作简单近轴换算。

Zernike：确定瞳心、半径和单位，读取结果中的 `(n,m)` 与归一化定义再比较系数。`rms_after_piston` 只去掉均值，未同时去掉倾斜和离焦。OPD 与相位转换需明确波长：`phase = 2π·OPD/λ`。

## 交付真实数据的最低可用件

准备一小组原始参考/样品、对应 dark/flat（若有）、上述实验记录、填完的 config、独立已知答案或重复测量，以及一份误差报告。保留原始文件，转换操作写进脚本。先跑小 ROI，再决定是否调用高性能原仓库处理整批数据。
