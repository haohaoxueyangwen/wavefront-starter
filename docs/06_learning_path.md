# 从入门到接入数据

下面按学习成果安排顺序，可用约两周，也可按自己的节奏推进。入口始终是 GitHub README 与在线文档；代码和配置通过克隆取得。

| 阶段 | 先读 | 操作 | 应交出的成果 |
|---|---|---|---|
| 1：概念与地图 | L34、L2；物理基础不足时补 L10 | 阅读 docs/03_methods.md | 一页术语表：复振幅、相位、OPD、偏折角、梯度、piston |
| 2：跑通环境 | README、docs/01_first_run.md | 独立环境 + check-env + 五案例 demo | report.json 中五案例均通过，能找到输入、配置与结果 |
| 3：散斑主线 | L17/L18 → L12/L16 → L5；选型时读 L4 | 单独跑 WXST 与 WSVT | 说明单对空间模板与多帧时间栈的区别，读懂 ux/uy 的符号与有效区域 |
| 4：光栅主线 | L13/L32 → L31 → L6/L27 | 跑光栅例子，核对边带配置 | 画出解调链，区分条纹相位与标定后的波前相位 |
| 5：Hartmann | L7 → L28 | 跑固定网格 Gaussian 光斑例子 | 说明参考点、质心、位移、距离与偏折角的关系 |
| 6：后处理 | L29、L30 | 跑 Zernike 例子，查看系数和残差 | 记录瞳心、半径、(n,m)、单位；区分 RMS、PV 和拟合残差 |

进阶阶段再读 L19/L9 的 UMPA、L21 的 PXST、L8 的 SPINNet，并转向原算法仓库开展对应任务。

## 初学时的几个关键区别

波前相位用 rad，OPD 用长度单位。条纹相位同样写 rad，却是干涉条纹的相位；需要灵敏度标定才能转换成波前信息。位移用 px，偏折角用 rad；像元与几何距离的定义要符合实际实验。

差分模式的 reference/sample 与绝对计量的参考定义不同。先说明数据是怎么采集的，再决定算法输入。当前散斑教学参考实现积分前去除位移均值，因此不提供绝对倾斜；Fourier 积分不提供绝对 piston。

WSVT / WXST 的默认示例是 BB11 CRL 真实数据；光栅、Hartmann、Zernike 另保留有明确解析答案的控制。实测 CRL 操作见 docs/14_crl_example.md，并检查背景、平场、坏点、坐标、标定与重复性。一次漂亮的图不能代替误差报告。

## 日常使用 GitHub

从 README 进入对应章节。新问题可以记录为 Issue，注明模式、配置键、报错、最小可分享样例与预期行为。同步更新前保留本地实验配置与结果，再执行 `git pull --ff-only`。研究结果使用自己的新目录，输入/输出数据默认不进入源码历史。
