## 初学时的几个关键区别

波前相位用 rad，OPD 用长度单位。条纹相位同样写 rad，却是干涉条纹的相位；需要灵敏度标定才能转换成波前信息。位移用 px，偏折角用 rad；像元与几何距离的定义要符合实际实验。

差分模式的 reference/sample 与绝对计量的参考定义不同。先说明数据是怎么采集的，再决定算法输入。当前散斑教学参考实现积分前去除位移均值，因此不提供绝对倾斜；Fourier 积分不提供绝对 piston。

WSVT / WXST 的默认示例是 BB11 CRL 真实数据；光栅、Hartmann、Zernike 另保留有明确解析答案的控制。实测 CRL 操作见 [CRL 案例](14_crl_example.md)，并检查背景、平场、坏点、坐标、标定与重复性。一次漂亮的图不能代替误差报告。

## 日常使用 GitHub

从 README 进入对应章节。新问题可以记录为 Issue，注明模式、配置键、报错、最小可分享样例与预期行为。源码用户同步更新前保留本地实验配置与结果，再执行 `git pull --ff-only`；完整包用户按 [升级步骤](18_results_and_faq.md#停止与升级)下载并解压到新目录。研究结果使用自己的新目录，输入/输出数据默认不进入源码历史。
