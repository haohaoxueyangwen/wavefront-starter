# 波前工作台：从按钮到数据

仓库首页是资料与代码入口。安装后，工作台在自己的电脑里运行，浏览器连接 `127.0.0.1`；实验图像不会发送到 GitHub。

## 启动

先按 [首页安装步骤](../README.md) 创建 Python 3.12 虚拟环境，安装依赖和本包。然后在仓库目录执行：

```powershell
.\.venv\Scripts\python.exe -m wfs_starter ui
```

浏览器默认打开 `http://127.0.0.1:8790/`。保留启动窗口。Linux/macOS 将解释器路径换成 `.venv/bin/python`。

端口占用时选择另一个端口：

```powershell
.\.venv\Scripts\python.exe -m wfs_starter ui --port 8791
```

希望自行打开浏览器或指定结果根目录：

```powershell
.\.venv\Scripts\python.exe -m wfs_starter ui --no-browser --workspace wavefront-runs
```

该界面不需要 Node、Qt 或另外的前端构建步骤。

## 一个工作区调用多个算法

左侧只保留四类功能：散斑追踪、光栅恢复、Hartmann 和波前分析。散斑页内选择 WXST 或 WSVT；所有功能共用右侧的结果、任务记录和运行控制。

主操作区按“数据 → 算法与参数 → 结果”排列。日常只填写输入和当前算法的必要参数；暗/平场、标定与高级设置、完整 JSON、数据文件和日志默认折叠。缺少必填标定时，会展开对应区域并定位待填写项。

## 先跑示例

1. 选择功能，散斑页再选择 WXST 或 WSVT，点击右上角“试用示例”。
2. 任务状态自动更新；运行期间不能重复提交，可点击“停止”。
3. 完成后直接看结果图。“数据文件与本次配置”中可下载数值数组、参数和合成控制报告。
4. 展开该区域，点击“载入本次输入与参数”，修改后点击“运行算法”，输出会放入新目录。
5. 左侧“任务记录”可查看此前任务。服务使用同一 workspace 重启后，已完成记录仍可加载。

## 共用数据，保留各算法设置

参考图、样品图、兼容的几何标定与暗/平场输入可在适用算法间保留；各算法的侧带、网格、圆瞳和搜索参数分别保留。浏览器刷新后可以恢复表单。表单草稿只保存在该浏览器的本地存储；换浏览器或电脑时使用“导出配置 / 导入配置”。

数据目录决定相对路径的含义。导入配置后，将其设为原配置文件所在目录；绝对文件路径可直接使用。输入需符合所选方法的实验条件，切换算法后应检查数据和参数再运行。

| 方法 | 输入与单位 |
|---|---|
| WXST | 一对灰度参考/样品图；同一方形 ROI；能量 eV、像素尺寸 m、距离 m |
| WSVT | 在表格中逐行填写参考/样品帧，用“添加配对”增行；至少两对且各像素有时间变化 |
| 光栅 | fftshift 侧带中心 `[行,列]`；窗口为奇数；输出差分条纹相位 rad，恢复物理波前需带符号标定 |
| Hartmann | 网格行列数；每格一个独立光斑；默认输出质心位移 px |
| Zernike | 二维相位 rad 或 OPD m；圆心 `[x,y]` px、半径 px；系数同输入单位 |

WSVT 配对表格保存为原算法的 `pairs` 配置，不会从单对图自动推断配对堆栈。扩展标定仍可在“标定与高级设置 → 完整配置 JSON”中添加，格式见 [实验数据说明](02_real_data.md)。

## 从恢复相位继续做 Zernike

完成的结果包含 `phase_rad` 时，会出现“Zernike 分解 →”。点击后将原数组无数值变更地导出为 `analysis-input/phase_rad.npy`，保留单位 rad、来源任务、算法、字段和尺寸，并在同一工作区切到波前分析。

填写圆心和半径后点击“运行算法”。坐标以恢复出的数组为准，散斑结果可能已经裁去边缘，应重新确认有效圆瞳；程序不会猜测瞳孔。来源记录保存在 `source.json`，也写入下游配置的 `phase_source`。手动更换相位路径后，下游配置会移除原来源标记。

接续保留来源单位 rad。如需用 OPD m 分析，应先进行物理单位转换，再选择转换后的新文件。

WXST / WSVT 的相位和已完成标定积分的光栅相位可接续。只有条纹相位的光栅结果、Hartmann 质心位移以及失败/停止任务不会出现此按钮，避免把不同物理量当成波前。Hartmann 的几何设计、动态恢复与焦点传播仍按完整原研究工程的流程操作。

## 停止、失败和断线

- “停止”只停止工作台启动的计算子进程。残留文件会保留供排查。
- 失败时日志自动展开，显示输入形状、空光斑、侧带或标定等问题。
- 断线点击“重新连接服务”；刷新会取得当前任务，不会重复提交。
- 每次任务有独立输出目录。运行期间保留启动窗口，或先停止再关闭。

## 原研究界面

本工作台用于统一教学流程。原散斑 Qt GUI、Hartmann 设计/旋转试验网页、Hartmann Qt、Zernike 与焦点分析 GUI 的本次修复已另存为 [增量补丁与维护说明](../maintenance/legacy-gui/README.md)，需要完整原研究工程才能使用；不要直接套到不同版本的同名仓库。

本次验证覆盖本机界面行为、任务生命周期与小型 CPU 合成案例。新工作台调用原教学求解器，真实实验的物理精度按各方法的数据与标定要求独立验证。
