# 波前工作台：从按钮到数据

仓库首页是资料与代码入口。安装后，工作台在自己的电脑里运行，浏览器连接 `127.0.0.1`；实验图像不会发送到 GitHub。

## 启动

先按 [首页安装步骤](../README.md) 创建 Python 3.12 虚拟环境，安装依赖和本包。然后在仓库目录执行：

```powershell
.\.venv\Scripts\python.exe -m wfs_starter ui
```

浏览器默认打开 `http://127.0.0.1:8790/`。保留启动窗口。Linux/macOS 将解释器路径换成 `.venv/bin/python`。

端口占用时选择另一个端口：

```powershell
.\.venv\Scripts\python.exe -m wfs_starter ui --port 8791
```

希望自行打开浏览器或指定结果根目录：

```powershell
.\.venv\Scripts\python.exe -m wfs_starter ui --no-browser --workspace wavefront-runs
```

该界面不需要 Node、Qt 或另外的前端构建步骤。

## 先跑示例

1. 在“处理方法”选择一种方法，点击“生成并运行示例”。
2. 任务状态显示运行中，日志自动更新；运行期间不能重复提交。
3. 完成后检查结果图、`metadata.json`、`results.npz` 和合成控制的 `report.json`。
4. 点击“将本次配置载入表单”，可以查看对应参数，修改后点击“检查并运行”，输出会放入另一个新目录。
5. 在“任务记录”切换已完成结果。使用相同 workspace 重启服务，已完成任务记录仍可加载。

| 方法 | 必须理解的输入与单位 |
|---|---|
| WXST | 一对灰度参考/样品图；同一方形 ROI；能量 eV、像素尺寸 m、距离 m |
| WSVT | 显式 `pairs` 配对帧列表；需要时间变化；不能用 WXST 的单对图替代 |
| 光栅 | fftshift 侧带中心 `[行,列]` 和奇数窗口；默认条纹相位 rad；物理梯度转换依赖带符号标定 |
| Hartmann | 固定网格的行列数；每格一个独立光斑；默认质心位移 px |
| Zernike | 二维相位 rad 或 OPD m；圆心 `[x,y]` px、半径 px；系数同输入单位 |

## 接入自己的数据

选择方法后填写表单。模板中的空标定项需要自行填写；程序不会补猜能量、距离、侧带、瞳孔或标定系数。

“数据基准目录”决定 `data/reference.npy` 等相对路径的含义。导入已有配置时，将它设为原配置文件所在目录；也可以直接填写绝对文件路径。

WSVT 的配对帧使用 JSON 数组编辑，例如：

```json
[
  {"reference": "reference/000.tif", "sample": "sample/000.tif"},
  {"reference": "reference/001.tif", "sample": "sample/001.tif"}
]
```

可选暗场、平场、光栅标定和扩展项在“高级配置 JSON”中添加，点击“应用 JSON 到表单”。完整格式见 [实验数据说明](02_real_data.md)。点击“导出配置”保存当前设置，后续可以重新导入。

点击“检查并运行”后，输入路径会被解析为绝对路径并保存在本次配置里，结果路径采用独立任务 ID；已有结果不会被覆盖。

## 停止、失败和断线

- “停止当前任务”只停止这个工作台启动的计算子进程。已经生成的文件会保留；已停止任务的残留文件不能当成完整结果。
- 运行失败时看日志末尾：缺失文件、输入形状、无时间变化、空光斑单元、侧带或标定问题都会显示在这里。
- 断线时点击“重新连接服务”。浏览器刷新会重新取得当前任务，不会重新提交计算。
- 关闭服务后，已完成记录和结果仍在 workspace 中；运行期间保留启动窗口，或先点击停止再关闭。

## 原研究界面

本工作台用于统一教学流程。原散斑 Qt GUI、Hartmann 设计/旋转试验网页、Hartmann Qt、Zernike 与焦点分析 GUI 的本次修复已另存为 [增量补丁与维护说明](../maintenance/legacy-gui/README.md)，需要完整原研究工程才能使用；不要直接套到不同版本的同名仓库。

本次验证覆盖本机界面行为、任务生命周期与小型 CPU 合成案例。新工作台调用原教学求解器，真实实验的物理精度按各方法的数据与标定要求独立验证。
