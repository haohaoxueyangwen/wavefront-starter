`examples/` 只提供模板导航；`build/`、`dist/`、`__pycache__/` 和 Numba 缓存由工具生成，不作为另一份源码维护。结果目录存放任务产物，按任务 ID 留存，不参与源码去重。

旧内部辅助接口需要回查时，在 Git 历史的 `9d400db` 提交查看对应文件。日常算法调用使用 `wfs_starter.core`、CLI 或工作台；内部 vendor 模块不是稳定公开 API。

## 原研究工程中的重复文件

本机原工程已经做过源码哈希盘点。同内容文件可能是冻结快照、独立项目所需的本地模块、兼容入口或带独有文件的旧版本，不能凭名字或单个文件哈希删除整个目录。

清理原工程时应逐项核对入口引用、独有源码、Git 暂存/未提交状态与实验记录绑定；只有完整保全并明确了替代入口的目录，才进入迁移或删除清单。冻结快照、数据与正在使用的兼容链接保留。
