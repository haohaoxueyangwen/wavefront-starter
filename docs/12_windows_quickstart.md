# Windows：解压后直接跑 WSVT / WXST

[文档目录](README.md) · [项目主页](../README.md)

给第一次使用的同学： **不用安装 Python、Visual Studio、Anaconda 或 CUDA Toolkit，不用找 EXE，不用配置环境变量。** 程序和运行库已放在 Windows 完整包里。

## 1. 下载哪一个文件

打开 [v0.6.3 发布页](https://github.com/haohaoxueyangwen/wavefront-starter/releases/tag/v0.6.3)，下载 **`wavefront-starter-0.6.3-windows-x64.zip`**。右键 ZIP → 全部提取。不要在 ZIP 预览窗口里双击启动。

GitHub 自动生成的 `Source code (zip)` 是开发源码，不是这里说的完整运行包。

## 2. 第一次先跑示例

1. 进入解压出来的目录，双击 **`start_speckle.cmd`**。浏览器会打开本机界面。
2. 选择 **WXST** 或 **WSVT**。初次使用先保持 **C++ CPU**。
3. 点击 **“载入 CRL 实测示例”**。程序填入 BB11 CRL 真实扫描数据的 512×512 中央区域与历史标定。
4. 点击 **“运行算法”**。右侧会出现位移、偏折角和相位图，下方能下载数值结果与本次配置。
5. 想试 GPU，就选择可用的 GPU 版本，再载入示例、运行。GPU 项变灰时，先用 CPU；原因显示在界面中。

“CRL · Python 参考”也载入同一真实数据，适合比较参考实现。检查随包 C++ / GPU 是否能用，应使用“载入 CRL 实测示例” → “运行算法”这条流程。

## 3. 不知道自己的电脑能不能用 GPU？

不需要师兄提前知道你的电脑型号。界面启动时自动检测程序、NVIDIA 驱动、显卡及 cuFFT 能否初始化。

| 你的电脑 | 应该选什么 |
|---|---|
| Windows 10/11，64 位 Intel / AMD CPU，没有独立显卡 | C++ CPU |
| Intel 核显、AMD 显卡 | C++ CPU；随包 GPU 程序使用 NVIDIA CUDA |
| 兼容的 NVIDIA 显卡，驱动正常，界面显示 GPU 可用 | 可选 GPU；先用示例测试 |
| NVIDIA 显卡存在，但 GPU 灰色或任务报错 | 先使用 CPU；按下方排错说明检查驱动 |
| macOS、Linux、Windows ARM | 本 ZIP 是 Windows x64 包；Linux 源码部署看 [原生指南](11_speckle_fast.md)，其他平台没有随包二进制验收 |

本包 GPU 编译包含 **SM60、61、70、75、80、86**，并附带 compute86 PTX，覆盖相应 Pascal、Volta、Turing、Ampere 架构，并给较新 GPU 提供驱动编译入口。 **包含编译支持不等于每个型号都实测过**：Windows 实测是 Quadro P5000 / SM61；Ada 和 Orin 的历史证据来自 Linux。较新显卡需以本机示例是否成功为准，尤其不承诺 RTX 50 系列直接适配旧 CUDA 11.6 的 cuFFT。

NVIDIA 驱动属于显卡本身，不在本 ZIP 内。通常机器已有驱动；需要更新时从 [NVIDIA 官方驱动页面](https://www.nvidia.com/Download/index.aspx)按型号下载安装。 **无需安装 CUDA Toolkit。**

内存与显存取决于数据尺寸。512×512 CRL 示例用于入门与检查流程；处理 2048²×100 帧 WSVT，建议主机内存 32 GB。GPU 速度配置在历史 Linux 测试中显式分配约 6.48 GiB，低内存配置约 4.26 GiB，不包含其他程序和驱动开销。显存较紧时选“低内存”、先裁 ROI，并关闭占用显存的其他程序；这些是容量参考，不能作为所有 Windows 显卡的实测性能。

## 4. 换成自己的数据

**WXST：一对图。** 在“参考图”“样品图”旁点击“浏览…”，选择对应 TIFF / NPY。预览确认二维灰度图、尺寸相同，填好实验标定后运行。

**WSVT：一组逐帧配对图。** 点击“参考帧目录”“样品帧目录”的“浏览…”，再点击“载入并核对配对列表”。按自然文件名排序配对，运行前检查每一行是否是同一个扫描位置。不能把两次不对应的扫描硬配在一起。

| 必须确认的参数 | 界面单位 | 随 CRL 记录载入 |
|---|---|---|
| 光子能量 | eV | 12400 eV = 12.4 keV |
| 探测器有效像元尺寸 | m | 1.625e-6 m = 1.625 μm；有放大倍率时用对应有效尺寸 |
| 传感器到测量平面的有效传播距离 | m | 0.4845 m |
| ROI、搜索与模板窗口 | px | 依数据和算法选择 |

CRL 示例标定沿用 BB11 既有重建记录，不是你新实验的参数。换数据时需一起修改这些数值。参考图、样品图、暗场、平场要来自可追溯的同一实验设置。

**CPU 版** 保留原界面搜索窗口、模板、扩展窗口、金字塔、小波、迭代、线程、分组和 ROI 参数。 **GPU 速度版** 固定搜索半窗 10、WXST 模板半窗 3（7×7）、扩展半窗 4、金字塔参数 1（两层）、cut1、迭代 1、小波开启；WSVT 必须 **100 对帧**。界面锁定这些固定项，其他资源和实验标定仍可改。帧数不同或需要其他算法参数时选 CPU；不能通过修改 JSON 让固定 GPU 内核变成另一套参数。

## 5. 结果在哪里，怎样理解

每次运行创建新目录，默认在解压目录的 **`local-runs`**。界面“运行日志与输出位置”可看完整位置；结果文件不会覆盖输入实验数据。

| 结果 | 含义 |
|---|---|
| `ux_px`、`uy_px` | X / Y 位移，像素单位；X 向右、Y 向下 |
| `angle_x_rad_demeaned`、`angle_y_rad_demeaned` | 按像元和距离换算、去均值的偏折角，rad |
| `phase_rad` | 积分后去活塞项的相位，rad；整体常数不从梯度测量恢复 |
| `results.npz` | 数值数组，供后续分析 |
| `metadata.json`、配置 JSON | 算法版本、标定、实际程序哈希与本次参数 |

固定 half10 的 GPU 重建结果比输入四边各少 10 px，例如 512×512 CRL 输入 → 492×492 位移 / 相位；透射率仍是 512×512。后续 Zernike 圆瞳坐标需要在输出数组上确定。CPU 版输出裁边随搜索窗口变化。

CRL 例子使用真实透镜数据，不设“已知刚体位移”或人为精度真值。数据裁剪、标定来源、原始文件校验和重建趋势见 [CRL 实测案例](14_crl_example.md)；Windows 原算法数值行为和旧工程检查保留在 [验证说明](13_windows_validation.md)。

右侧“Zernike 分解 →”会带着真实相位、rad 单位和来源打开独立波前分析界面。 **当前接续不会自动填写实验能量与像元：CRL 案例需手动将光子能量设为 12.4 keV、像元设为 1.625 µm，再拖画圆瞳并运行。** 新页面的 15 keV / 0.65 µm 是旧界面默认值，不能直接用于这组 CRL；输出只裁边、不缩放，像元尺寸不变。光栅、Hartmann、波前分析分别从 `start_grating.cmd`、`start_hartmann.cmd`、`start_wavefront.cmd` 启动；这些是独立界面。随包可运行基础光栅 / Hartmann 质心和完整 Zernike。Hartmann 设计 / 旋转、曲率 / 焦点的原工程扩展仍需对应研究工程，范围与来源见各模块文档；本次 Windows 二进制验收覆盖 WSVT / WXST。

## 常见问题

| 现象 | 操作 |
|---|---|
| 找不到 Python、EXE，或缺少 DLL | 确认下载的是 Windows 完整包并全部解压。不要只复制启动 CMD 或 EXE，保留 `runtime` 目录 |
| GPU 不可用 / 驱动版本不足 / cuFFT 出错 | 看界面给出的设备检测原因；先用 CPU，再检查 NVIDIA 官方驱动。不要安装一堆不同版本 CUDA 来碰运气 |
| GPU 显存不足 | 选 WSVT 低内存，缩小 ROI，关闭其他占显存程序；仍不足时选 CPU |
| WSVT 报“恰好 100 帧” | 固定 GPU 版本只接受 100 对帧；其他帧数选 CPU |
| 报“找不到输入文件” | 重新浏览选择实际位置；导入别人配置时，里面的路径属于别人的电脑 |
| 刚换新版却还是旧界面 | 先停止任务，用原运行目录的 `stop_frontends.cmd` 关闭后台，再启动新版 |
| 另一份目录的后台占用 8790 | 到那份目录运行 `stop_frontends.cmd`，然后再打开新版；不要批量结束所有 Python 进程 |
| 只想关浏览器 | 可以直接关；后台继续运行。需要完全退出时，在任务完成后双击 `stop_frontends.cmd` |
| 要升级 / 换电脑 | 解压新包到新目录，把自己的数据和结果另行保留。不要把新包覆盖到实验数据目录 |

深入参数与 Linux 部署看 [高速散斑指南](11_speckle_fast.md)，入门概念和文献从 [学习路线](06_learning_path.md)开始。
