# 光栅：从边带到差分条纹相位

[文档目录](README.md) · [标定与数据](02_real_data.md) · [光栅配置模板](../src/wfs_starter/configs/grating.json)

入口是 `start_grating.cmd`。本界面处理一对相同尺寸的二维灰度 TIFF / NPY，分别是参考条纹与样品条纹；先做频域边带解调，有明确标定后才能积分为波前。CRL 散斑帧不适用于本流程。

## 先看一次已知答案

点击右上角“试用示例”，程序执行128×128的两方向解析载频控制。参考图有两组周期条纹；样品条纹按已知相位的导数编码。示例 X / Y 边带中心分别为 `[64,74]` / `[74,64]`，窗口均为 `[9,9]`。

结果目录含输入、配置和 `report.json` 数值指标。示例使用1 µm采样、梯度系数 `[1e6,1e6]`，仅适合这个解析编码；这些数值不是实验 Talbot 系统的标定值。

## 换成实验条纹

1. 用“浏览…”选择数据目录、参考图和样品图，核对相同尺寸、方向、曝光和实验设置。按需选择同设置的暗场 / 平场。
2. 点击“预览输入 / 选择区域”。右侧显示参考图的 **fftshift 频谱**，中央亮点是零频 DC。
3. 在预览上选择“点击选择 X 侧带”，点击对应的一阶边带中心；再选 Y 并点另一组边带。坐标为 **`[行,列]`**，不是 `[x,y]`。X / Y 标签需要与实验的敏感方向对应，不仅凭亮点位置命名。
4. 调整 X / Y 窗口的行数与列数。使用正奇数，包含需要的边带，避开 DC、共轭侧带和其他级次，且不能超出频谱。可比较几个合理窗口对结果的影响。
5. 先保持波前恢复关闭，按需展开条纹相位，点击“运行算法”。观察两方向差分相位是否连贯，边缘与低调制度区域是否异常。
6. 有标定时再开启波前恢复，填写下面的全部字段，导出配置后运行新任务。

## 参数与标定

| 配置键 | 填写规则 |
|---|---|
| `band_x_center_rc` / `band_y_center_rc` | fftshift 频谱内的整数 `[行,列]`；不能是 DC，也不能是同一个点 |
| `band_x_size_rc` / `band_y_size_rc` | `[行数,列数]`，正奇数，默认 `[9,9]` |
| `unwrap` | 是否展开差分条纹相位；关闭时输出包裹相位 |
| `recover_wavefront` | 是否用标定系数换算梯度并积分，模板默认关闭 |
| `phase_gradient_scale_rad_per_m_per_fringe_rad` | 两个有限、非零、有符号的 `[X,Y]` 系数，单位 rad/m per fringe rad |
| `pixel_size_x_m` / `pixel_size_y_m` | 积分平面上的 X / Y 采样间距，m，必须为正 |
| `calibration_source` | 记录几何推导、标准样品或标定记录的身份及符号约定 |

换算为 `gradient_x = fringe_phase_x × scale_x`，Y 同理；再按采样间距进行 Fourier 积分。共轭边带会改变相位符号，因此边带选取和有符号系数必须一致。系数取决于能量、几何、光栅参数和成像倍率，不能直接复制解析示例；没有这些记录时保留差分条纹相位结果。

## 结果和后续分析

| 数值字段 | 含义 |
|---|---|
| `fringe_phase_x_rad` / `fringe_phase_y_rad` | 样品相对参考的差分条纹相位，rad |
| `phase_gradient_x_rad_per_m` / `phase_gradient_y_rad_per_m` | 开启标定后的波前梯度，rad/m |
| `phase_rad` | 开启标定后的积分波前相位，rad；Fourier 周期边界，piston 被去除 |

PNG 用于查看，`results.npz` 用于数值分析，`metadata.json` 记录约定与标定来源。只有得到标定后的 `phase_rad` 才能使用“Zernike 分解 →”；完整 Zernike 还需填写实际光子能量、像元和有效圆瞳。不要将条纹相位直接当作透镜波前。

找不到边带时先核对是否有可分离的两方向载频；本适配器要求两个不同的 X / Y 边带，不提供单方向条纹补全。边带过宽、强噪声或展开跳变时，回看原图、调制度、窗口和暗 / 平场。[结果与排错](18_results_and_faq.md)说明怎样保存完整任务用于复查。
