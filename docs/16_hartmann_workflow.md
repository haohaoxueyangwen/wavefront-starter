# Hartmann：固定网格、质心与偏折角

[文档目录](README.md) · [数据与标定](02_real_data.md) · [Hartmann 配置模板](../src/wfs_starter/configs/hartmann.json)

入口是 `start_hartmann.cmd`。主页面用同一固定网格，分别计算参考图和样品图每格的强度质心，再取样品减参考的位移。它适合规则、孤立且没有越过格边界的光斑；网格划分覆盖整张输入图。

## 先跑解析控制

点击“试用示例”。程序生成128×128、4×4孤立 Gaussian 光斑，已知整体偏移为 `ux=+0.35 px`、`uy=−0.20 px`。解析几何为像元1 µm、距离0.5 m，对应角度约 `+0.70 µrad` / `−0.40 µrad`。这些是控制的已知答案，与 CRL 实测散斑没有关系。

检查位移的方向、量级和16格是否一致，再打开本次配置与结果。完整实验输入不应直接使用这些示例几何参数。

## 换成自己的光斑图

1. 用“浏览…”分别选择参考图和样品图，要求二维灰度、相同形状、相同方向。参考图应与所采用的波前参考定义一致。
2. 填写网格行数和列数，点击“预览输入 / 选择区域”查看网格。每格需容纳同一个对应孔的单个完整光斑，且参考与样品都不能有空格。
3. 如果输入周围留有大边框、光斑不在规则网格里，先在自己的处理副本中裁剪成适合固定分格的区域，并记录裁剪坐标；主界面不提供自动孔识别与光斑配对。裁剪参考与样品必须一致。
4. 按实际情况选暗 / 平场。过高或不均匀背景会改变强度质心，需检查背景处理；主页面没有自动背景阈值分割。
5. 先关闭角度转换，运行并检查参考 / 样品质心以及 `ux_px`、`uy_px`。X 向右、Y 向下，符号为样品减参考。
6. 确认实验几何后，开启角度转换，填写有效像元与实际传播距离，再运行新任务，保存配置。

## 参数和结果

| 配置键 | 说明 |
|---|---|
| `grid_rows` / `grid_cols` | 正整数；每格至少4×4像素；不是光斑自动搜索数量 |
| `convert_angles` | 是否按标定换算偏折角；模板默认关闭 |
| `pixel_size_m` | 有效像元，m，包含需要的成像倍率修正 |
| `distance_m` | 与测量几何对应的有效传播距离，m，必须为正 |

小角度换算为 `angle_x = ux_px × pixel_size_m / distance_m`，Y 同理。若存在不同轴倍率或更复杂几何，应先明确如何映射到此标量几何模型。

| `results.npz` 字段 | 数值意义 |
|---|---|
| `reference_centers_xy_px` / `sample_centers_xy_px` | `[网格行,网格列,2]`，最后一维为 `[x,y]`，位置在输入图坐标中 |
| `ux_px` / `uy_px` | `[网格行,网格列]` 的质心位移，px |
| `angle_x_rad` / `angle_y_rad` | 开启转换时输出的偏折角，rad |

位移图的一个像素代表一个网格光斑，不是探测器的一个像素。主页面输出质心位移与角度，不自动积分相位，因此没有主页面到 Zernike 的相位接续。

## 设计、动态仿真与旋转功能

顶部“孔阵列设计与动态仿真 →”“旋转参数与时序试验 →”保留原研究工程的完整服务页面，需要设置 `WFS_HARTMANN_PROJECT` 为包含 `modes/xray/visualization` 的工程目录，并安装原工程依赖。这些扩展不随独立包即用；准备方法见 [开发指南](19_development.md)和 [界面总览](08_interfaces.md)。

如果提示空格或质心异常，核对孔阵列与网格是否匹配、光斑是否越界或混叠、参考是否同孔。旋转掩膜或动态混叠需用对应研究模型分析，不能靠增加固定网格数解决。[结果与排错](18_results_and_faq.md)给出日志和复跑方式。
