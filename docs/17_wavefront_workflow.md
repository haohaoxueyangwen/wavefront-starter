# 波前 / Zernike：完整操作流程

[文档目录](README.md) · [原界面功能对照](10_zernike_parity.md) · [完整配置模板](../src/wfs_starter/configs/zernike_full.json)

双击 `start_wavefront.cmd`，默认使用“完整 Zernike · 原手动圆瞳分析”。这一入口保留完整参数和报告，适合已恢复的二维相位 rad；教学15项、自动ROI曲率、焦点扫描是另外的选项。

## 先跑完整的50项例子

1. 点击“导入配置”，选择解压目录中的 `examples/full_zernike/config.json`。
2. 将“数据目录”浏览选择为 `examples/full_zernike`。配置中的相对相位路径将从这里解析。
3. 点击“预览输入 / 选择区域”，应看到64×64相位，圆心 `[31.5,31.5]`、半径28、50项、去除径向阶数0–2，能量15 keV、像元0.65 µm。
4. 运行，查看全部系数、完整报告、高阶图和全部拟合残差。拟合残差接近零，高阶 RMS 仍非零：去除低阶与去除全部拟合项是两种运算。
5. 查看 `expected.json` 的已知系数与指标，用数值文件核对答案。该解析例子用于检查分析流程，不代表真实透镜测量精度。

完整模式的“试用示例”按钮不启用，按上面的导入配置步骤操作。源码或完整包的命令行见 [已知波前示例](../examples/full_zernike/README.md)。

## 分析 CRL 或自己的相位

散斑结果中点击“Zernike 分解 →”可带入相位路径、rad单位与来源。 **v0.6.4 从成功的散斑结果 metadata.json 自动传递能量和像元；不使用尚未运行的表单参数。** 对 BB11 CRL，核对页面已填写 **12.4 keV、1.625 µm**，然后在492×492结果图上画圆瞳。裁边不改变像元，中央裁剪分析也不等于整枚透镜的全口径评价。

自己已有相位时，浏览选择二维 `.npy`。完整入口要求 rad，相位的圆瞳内必须有限；圆瞳外可以为 NaN。如果已有 OPD，先在另存副本中按 `phase_rad = 2π × OPD_m / wavelength_m` 转换，并记录实际能量和长度单位。PNG 或带色标图片不能作为数值相位输入。

## 参数逐项填写

| 参数 / 配置键 | 含义与操作 |
|---|---|
| 相位 `phase` | 二维 NPY 路径；相对路径以数据目录为基准 |
| 单位 `phase_unit` | 完整入口固定 rad；OPD m 仅在教学入口直接支持 |
| 像元 `pixel_size_um` | µm，范围0.001–1000；裁剪后不变，重采样后需更新 |
| 光子能量 `photon_energy_kev` | keV，范围0.1–100；派生波长在页面显示 |
| 圆心 `center_xy_px` | `[x,y]`，即 `[列,行]`，可用小数，使用输入数组坐标 |
| 半径 `radius_px` | px，圆瞳须位于图内且覆盖有效数据；不把遮挡或坏点纳入 |
| 项数 `terms` | 5–50，标准 Noll 顺序；用相同圆瞳比较不同项数 |
| 去除阶数 `max_order_remove` | 0–10，去除已拟合项中径向阶 `n <= 此值` 的项；不是去掉前几项 |
| 输出目录 `output_root` | 浏览选择；留空使用默认任务位置 |
| 文件名前缀 `run_name` | 写入 `前缀_任务ID` 新子目录；不覆盖旧结果 |
| TIFF `export_tiff` | 导出带色标和原始 float32 TIFF；NPY / NPZ 同时保留 |

默认15 keV / 0.65 µm来自旧界面，不是程序推断的实验标定。改变能量或像元会改变 waves 与曲率尺度，因此报告中要同时保存这些参数。

## 如何画圆瞳

预览后选择“拖画圆瞳”：从圆心按下并拖到边界；或直接填写圆心 X / Y与半径。“移动圆瞳”用于调整位置，“点击选择瞳孔半径”用于调整大小。滚轮 / 缩放按钮仅改变显示比例；“平移视图”可浏览放大图，“重置”恢复视图。选区始终使用原数组坐标。

比较两次处理时应使用相同坐标系和同一有效口径。半径变化会改变拟合基底、系数和 RMS，不能将不同口径的报告直接当成算法优劣。

## 报告怎样看

| 指标 / 图 | 含义 |
|---|---|
| 整体 PV / RMS | 圆瞳内原相位的峰谷值 / 标准差；RMS 已去 piston |
| 高阶 PV / RMS | 原相位减去所选径向阶数的低阶拟合背景 |
| 全部拟合残差 PV / RMS | 原相位减去全部已拟合项，不等于高阶像差 |
| 系数 | 全部 Noll j、(n,m)、rad、waves，以及该项是否被去除 |
| Rx / Ry / 平均 ROC | 原程序 j4 / j6 的固定轴公式，mm；不是考虑旋转像散后的主曲率轴 |
| 五种相位图 | 圆瞳内原相位、全拟合、低阶背景、高阶像差、全拟合残差 |

原 Noll 映射和波长单位的两项修正及追溯方式见 [功能对照](10_zernike_parity.md)。比较历史旧错误实现时需保留这种差别。

## 保存与后续使用

结果面板提供完整报告 / 高阶 PNG、五种数值图 NPY、TIFF、`results.npz`、系数 CSV、`summary.json`、`metadata.json` 和文本报告。原始数值用于后续计算；带色标的图用于展示。点图可放大、平移、翻页和下载；日志面板可打开结果文件夹。

“教学 Zernike”是1–15项简化教学拟合，支持 rad 或 OPD m；“高度 / 曲率与残差”“焦点扫描”调用原研究工程，需要额外准备工程及依赖。选择完整手动入口即可用随包功能。[结果与复跑](18_results_and_faq.md)说明如何保留配置和升级。
