## 一次任务保存什么

网页默认保存到解压目录 `local-runs/`；日志面板显示实际位置。每次有独立任务ID，失败与取消也保留记录。原实验输入不复制到每个结果目录。

```text
local-runs/
  <任务ID>/
    config.json         本次实际配置
    job.json            状态及任务位置
    run.log             计算日志
    results/
      results.npz       数值数组
      metadata.json     坐标、单位、标定、来源
      *.png             展示图
```

完整 Zernike 自选输出目录时创建 `前缀_任务ID`，分析文件及记录以界面显示位置为准；另有系数 CSV、摘要 JSON、文本报告、NPY和TIFF。网页“试用示例”将解析控制保存在任务的 `demo/<case>/` 下；普通网页运行则按上图保存。CLI `demo` 是 `<输出>/<case>/config.json` 加 `results/`；普通 `run --output 新目录` 则把结果直接写入指定新目录。

至少保留 **本次配置、数值结果、metadata、日志和输入身份**。展示PNG不是原始相位或位移；NPZ可在源码环境读取：

```python
from pathlib import Path
import numpy as np

with np.load(Path("你的结果目录") / "results.npz", allow_pickle=False) as result:
    print(result.files)  # 先看本模式实际有哪些字段
    # 散斑或标定光栅结果：phase = result["phase_rad"]
```

各算法的字段不同，Hartmann位移是网格数组，Zernike含圆瞳掩膜；读取前查对应操作指南。

## 配置怎么复用

- 同电脑：在任务记录里选择已完成任务，点击“载入本次输入与参数”，核对后运行新任务；也可导出配置后在同一工具页面“导入配置”。
- 换电脑：旧配置可能有绝对路径。重新浏览选择数据目录及输入，WSVT重新生成并核对配对表。CRL直接重新“载入 CRL 实测示例”。
- 配置模板中的 `null` / 空路径代表需要填写。光栅梯度和Hartmann角度转换关闭时，其标定占位项不参与计算；打开转换必须填真实参数。不要批量把占位项都替换成示例常数。
- CLI：`run 配置路径 --output 新结果目录`，相对输入按配置文件所在目录解析。网页导入配置后，另核对“数据目录”；两者的基准规则不同。

## 停止与升级

任务中点击“停止”终止对应计算进程树，保留日志和记录。使用完毕双击 `stop_frontends.cmd` 关闭本包服务。只关浏览器页签不一定停止后台。

升级完整包：保留旧包和其中自己的配置 / `local-runs`，停止旧服务，把新ZIP解压到新目录，先跑随包例子，再浏览选择自己的输入。不要覆盖旧包做升级。界面状态按本机工作区保存，换目录后需要重新选数据；跨机器结果浏览不保证自动识别旧路径。

开发者在干净工作区执行 `git pull --ff-only`，先保留自己的未提交修改。算法或依赖变化按新版本指南更新；文档版本不能当作新硬件或新精度验收。

## 故障排查

| 现象 | 先检查 |
|---|---|
| 双击后报缺文件、没有Python | 是否下载 `windows-x64` 完整包并全部解压，而非 Source code |
| 检测到旧版后台 / 页面仍旧 | 完成或停止任务，运行旧包的 `stop_frontends.cmd`，再启动新包；刷新页面 |
| GPU选项不可用 | 读取界面检测原因；先用CPU，核对NVIDIA驱动和支持条件，运行 `check_windows.cmd` |
| GPU可检测但计算失败 | 保存原错误；核对100帧与固定参数、ROI和显存；不会自动转CPU掩盖错误 |
| 文件或配置找不到 | 检查当前数据基准目录、相对路径、旧电脑绝对路径及文件是否齐全 |
| WSVT无跨帧变化 | 配对是否正确，是否复制了一帧，是否有死像素；同一帧重复不能构成时间向量 |
| 光栅侧带无效 | DC、窗口越界、偶数窗口、X/Y选了同一个点；核对两方向载频 |
| Hartmann空格 / 位移跳变 | 网格和孔是否一致、光斑是否越界 / 重叠、是否有空格与背景污染 |
| Zernike无效瞳孔或有限点不足 | 圆心为 `[x,y]`、圆在图内、圆瞳内相位有限、选区没有坏点 |
| Zernike曲率尺度不对 | keV和eV、µm和m、相位rad和OPD、裁边后的坐标；CRL为12.4 keV / 1.625 µm |
| 输出目录已存在 | 使用新的CLI输出目录，保留旧任务，不删除旧结果来强行复跑 |
