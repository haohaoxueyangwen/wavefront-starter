# 已有研究界面的修复记录

本次已在维护副本中修复散斑、Hartmann Web/Qt、旋转参数试验、Zernike 和焦点分析界面。这里保存本次增量补丁，便于对照和迁移；这些补丁需要对应的完整原工程，教学同学直接使用 [波前工作台](../../docs/08_interfaces.md)。

`manifest.json` 记录每个目标的相对路径、修改前后 SHA-256 和补丁名。历史工程、当前研究工程及公开算法仓库的版本不同；不要把这些补丁直接套到名字相似的公开仓库。原有未提交修改已先保全，补丁只包含本次界面维护的差异。

修改内容：

- 散斑 GUI：运行中关窗不会销毁计算线程；启用暗/平场时必须选择存在的校正图。
- Hartmann Qt：按钮在线程真正结束后恢复；运行中拦截关窗。
- Hartmann Web：防止设计预计算阶段重复提交；校验数值范围；修正六个默认值与 HTML step 的冲突；复制 JSON 显示结果；异常 JSON 响应明确报错。
- Hartmann 服务：输出目录附加 UUID，避免 Windows 时钟分辨率造成同名任务目录碰撞。
- 旋转参数试验：保留待完成 job ID，刷新或断线后可重连；状态查询超时给出提示；阻止未完成任务重复提交。
- Zernike 像素分析：阻止重复运行与运行中关窗；校验文件、运行名称和 δ；保护已有同名输出；修正缩放读数；成功/失败恢复操作。
- 旧 Zernike 分析：允许零坐标 ROI；新数据使旧 ROI 和结果失效；使用参数快照；补上缺失的线程初始化及默认输出目录传递。
- 焦点分析：原停止标记接入加载/批处理/保存流程；在处理边界响应取消；保留无取消调用的原处理顺序；不再覆盖 QThread 的原生 finished 信号。

科学求解器、物理参数和原验收阈值保持原值。散斑原文件中的 Argonne 声明继续保留，见 [版权声明](../../provenance/LICENSE-ARGONNE.txt)。

## 迁移补丁

先对照 `manifest.json` 的项目、路径和修改前哈希，在原工程根目录逐个检查对应补丁。使用绝对补丁路径，执行：

```powershell
git -c core.autocrlf=false apply --check <补丁路径>
git -c core.autocrlf=false apply <补丁路径>
```

只在检查通过、基线一致的副本中应用；已经修复的维护副本无需重复应用。显式关闭自动换行转换是为了保留原文件的换行格式。本次 11 个补丁已逐一应用到基线副本并核对修改后文件哈希。
